XSS Sanitization & CSP

Cross-Site Scripting audits test whether untrusted user inputs are properly encoded or sanitized with tools like DOMPurify before DOM insertion, alongside enforcing strict Content Security Policies (script-src 'self').

SQL Parameterization

SQL Injection tests verify that all database interactions employ parameterized queries (Prepared Statements) or Object-Relational Mappers (ORMs), ensuring attacker-controlled strings cannot break out of SQL execution boundaries.

CSRF & SameSite Defenses

Cross-Site Request Forgery test vectors ensure that state-changing API endpoints validate anti-CSRF synchronizer tokens and configure cookies with SameSite=Lax/Strict and HttpOnly attributes.
