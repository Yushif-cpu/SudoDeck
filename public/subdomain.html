Certificate Transparency (crt.sh)

Certificate Transparency (CT) is an open public audit framework for monitoring TLS/SSL certificates issued by public Certificate Authorities. CT logs allow security analysts to identify unlinked subdomains, internal staging environments (staging.corp, dev-api), and third-party SaaS integrations purely through passive reconnaissance without sending a single network packet to the target server.

HackerTarget DNS Host Search

The HackerTarget Host Search engine interrogates forward DNS mapping records to correlate subdomains with active IP addresses and infrastructure hosts. This rapid triangulation helps identify origin servers, load balancers, CDN edge nodes (Cloudflare, Akamai, AWS CloudFront), and misconfigured public development hosts.
